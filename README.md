# OSCE3 Haul

My study notes and curated references for the three OffSec certifications that make up **OSCE3**:

| Cert | Course | Focus | Folder |
| --- | --- | --- | --- |
| **OSEP** | PEN-300 | Evasion-focused penetration testing and lateral movement | [`osep/`](osep/) |
| **OSED** | EXP-301 | Windows user-mode exploit development | [`osed/`](osed/) |
| **OSWE** | WEB-300 | White-box web application exploitation | [`oswe/`](oswe/) |

Clearing all three earns the **Offensive Security Certified Expert 3 (OSCE3)** designation.

## What this is

A personal learning repository: my own notes, topic outlines, lab logs, and links to primary sources. It is organised by course so I can track what I've covered and where I'm weak.

## What this is not

- **Not exam content.** OffSec exams are under NDA. Nothing here reproduces exam machines, flags, or walkthroughs.
- **Not a dump of anyone else's notes.** Where another author's material helped me, I link to it and credit them rather than copying it. See each folder's references.
- **Not a drop-in toolkit.** These are study notes. Anything technique-specific stays at the level of the public course syllabus and points to the original research.

## How it's organised

Each folder has its own `README.md` acting as an index for that course: the syllabus domains, a prep checklist, lab setup notes, and references. Topic notes live alongside it as they're written.
